# Real Estate Lead Scoring & Follow-up

Independent, explainable scoring demo. Node 20+: `npm start`, visit `http://127.0.0.1:4204`, run `npm test`. The score reflects budget fit, timeline, preferred area, property type and financing readiness. It is a prioritization rule, not a conversion probability.

The UI drafts a three step WhatsApp and email sequence and exports it as JSON for review. It does not send. Before real automation, add CRM deduplication, consent checks, quiet hours, opt-out handling, agent approval and approved provider credentials.
